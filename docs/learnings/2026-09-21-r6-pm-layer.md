# R6, the PM layer: what the build taught about the loop

Milestone 6 "R6 — PM layer" (#109 to #113, #122), closed 2026-09-21 with 0.3.0.

## Context

Five skills and a CLI seat, built across two sessions in the house pattern. An orchestrating session on Fable brainstormed, then wrote the spec and a plan whose every expected value was measured in a throwaway worktree. It handed the plan to a worker session on Opus running subagent-driven-development. The worker ran 28 agents over 108 minutes and 26 commits; the orchestrator ruled on 14 escalations. Issue #121 holds the numbers.

## Lesson

Specific expectations disagree with reality; vague ones read as noise. The plan's measured numbers caught three plan defects before any code ran. Two of them were numbers the orchestrator's own pre-flight had produced: true in its finished worktree, false at the worker's step. The check that finds plan defects is the worker's raise-before-acting scan, run in the environment where the plan executes. Building the end state first makes the plan's numbers true somewhere else.

The gates catch what they are written to catch; the reviews catch what nobody thought to write a gate for. The three most serious defects on the branch were found by review seats and by nothing else. One was a board write command that could not run. One was a renderer regex that broke its own six-line contract on multi-line input. One was a release comment aimed at issues nobody resolved. All three passed the suite, the type check, the linter, and both plugin validations throughout. Implementer self-review surfaced nothing a later stage did not, and twice asserted a check it had not run.

A first run following the prose is the test for prose. Bootstrapping furnace from the skill text caught `gh project link` rejecting `--owner @me`. Closing R6 through `sk-milestone` caught that its learning record is written after the tag, so the release cannot carry it.

## Consequences

The pre-flight-by-building-the-end-state stops being the default; the worker's scan and superpowers' plan self-review stay, and expectations are stated as things to measure. Reviewers are told to verify compliance claims rather than credit them. `sk-language.md`'s sentence limit gets a ruling on code spans (#124). The sentence-count check that let this record's neighbours through now fails the commit rather than printing. The next milestone's close moves the learning record before the tag, once ruled on the issue filed from this run.
