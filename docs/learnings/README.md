# Learnings

One record per closed issue or milestone that clears the bar, linked from the close comment that produced it. Issue #112 opened the folder.

The bar, the shape, and the lifecycle are the plugin's default, in `plugin/skills/sidekick/references/docs-layout.md` §learnings/. `sk-track` and `sk-milestone` use them in any repo whose learnings README states no shape of its own. This repo adds nothing to them.
